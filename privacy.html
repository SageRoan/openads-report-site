Política de privacidad

Última actualización: septiembre de 2026

Esta política describe cómo OpenAds Report, una herramienta de uso interno de OpenAds, accede y utiliza datos de las APIs de Google Ads y Google Analytics 4 (GA4).

Quién usa esta aplicación

OpenAds Report es de uso exclusivamente interno: la utiliza el equipo de OpenAds para generar reportes de desempeño publicitario para sus propios clientes de agencia. No es un producto distribuido públicamente ni disponible para terceros fuera de OpenAds.

Datos a los que accede

La aplicación solicita acceso de solo lectura a:

  • Google Ads API (scope adwords): datos de cuentas, campañas, grupos de anuncios y métricas de rendimiento (gasto, clics, conversiones, etc.) de las cuentas publicitarias que OpenAds administra.
  • Google Analytics Data / Admin API (scope analytics.readonly): propiedades, dimensiones y métricas de tráfico y comportamiento de los sitios web de esos mismos clientes.

Cómo se usan los datos

  • Generar reportes periódicos (mensuales/quincenales) de desempeño de campañas para cada cliente.
  • Consolidar métricas de Google Ads y GA4 en un mismo documento de reporte.
  • Ningún dato se utiliza para entrenar modelos de machine learning, publicidad, ni ningún fin ajeno a la generación de estos reportes.

Qué NO hace esta aplicación

  • No comparte, vende ni transfiere datos a terceros bajo ninguna circunstancia.
  • No modifica campañas, presupuestos ni configuraciones — todo el acceso es de solo lectura.
  • No otorga acceso a personas fuera del equipo de OpenAds; las credenciales de la aplicación no se distribuyen.

Almacenamiento y retención

Los reportes generados se almacenan de forma privada en los sistemas internos de OpenAds. Las credenciales de acceso (tokens OAuth) se guardan de forma privada y nunca se incluyen en código fuente ni en repositorios públicos. Los datos crudos consultados a las APIs no se conservan más allá de lo necesario para generar cada reporte.

Revocar el acceso

Cualquier cuenta de Google conectada a esta aplicación puede revocar el acceso en cualquier momento desde la configuración de la Cuenta de Google, buscando "OpenAds Report" en la lista de aplicaciones conectadas.
